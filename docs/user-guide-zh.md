# Lake Shore 336 温度控制程序

默认界面语言为 **English**。右上角 **English / 中文** 可即时切换，并记住选择。切换语言不改变温度点、保持时间、运行状态或数据记录。英文使用说明见 user-guide-en.txt。



双击 **LakeShoreControl.exe** 运行。这个文件夹包含可执行程序、配置文件、源代码和构建脚本，不需要安装 Python 或 LabVIEW。使用 Windows 自带的 .NET Framework 4.7.2 或更新版本。

当前版本启动时自动载入 `recipes/默认温度程序.json`：80 K 到 298.15 K 的 23 点定时阶跃程序，每次增加 10 K，最后从 290 K 到 298.15 K；每点设定目标后立即计时（当前默认配方为 22 分 22 秒，可在 GUI 填写 22:22 调整；以实际载入表格为准）。**载入不等于执行**，连接设备后点击“开始程序”。

## 连接与首次控温

1. 在 336 面板选择 **Interface → Enabled → USB**。关闭占用同一串口的其他软件（例如 MeasureLINK）。
2. 在界面选“真实设备”和串口（这台电脑已识别为 **COM6**），点击“连接”。连接只读取信息，不改变当前温度目标或加热档位。
3. 选择控制输入 A–D、加热输出 1 或 2。本装置此前读到的是 A 输入、输出 1；程序不会把未接传感器的 0 K 当作有效测量。
4. 确认加热档位。无需填写最低、最高温度；当前定时阶跃程序直接从表格第一个目标开始。连接时显示仪器当前启用的加热档位。
5. 手动控制：填写目标温度（K 或 °C）及变化速率（K/min），点击“应用手动目标”。到温后持续恒温，直到停止。
6. 程序控制：编辑左侧温度段，点击“开始程序”。开始前会检查每一段的范围、时间、输入状态与仪器已配置的输入温度上限。

**连接并不等于开始控温。只有“应用手动目标”或“开始程序”会执行温度设置。** 加热器接线、传感器曲线、额定电流与电阻必须已在仪器上正确配置；程序保留这些配置。

## 温度梯度与时间

右侧顶部新增 **每点保持 min / 分:秒** 输入框。填写分钟数（支持小数）或分:秒（例如 24:28 为 24 分 28 秒）后点击 **应用到全部点**，会统一更新所有温度点、刷新总览并保存为默认程序，下次打开保留。此操作不启动序列；运行时锁定，暂停后可修改。暂停时编辑的是新方案，当前目标和已有计时保持不变；修改后点击“重新开始”执行新方案，避免“继续”误用旧参数。填写时长必须大于 0、小于每段总超时；单点不同时长和温度目标可在“编辑程序表（可滚动）”中调整。暂停后也可以添加、删除、生成或导入温度点。

| 列 | 含义 |
| --- | --- |
| 目标 K | 该段最终温度，固定使用开尔文。°C = K − 273.15。 |
| 变化方式：速率 | “梯度值”填 K/min。程序根据起点与终点自动决定升温或降温。 |
| 变化方式：时间 | “梯度值”填 min，即设定值从本段起点移动到目标所用的时间。 |
| 变化方式：阶跃 | 直接把设定值切换到该段目标温度。“梯度值”显示 — 并被忽略，不限制实际升降温速率。 |
| 变化方式：定时阶跃 | 直接写入目标，回读确认后立即开始计时；不等待实测到温，超差不清零。 |
| 保持 min / 分:秒 | 定时阶跃：目标保持时长。其余方式：实测到温稳定后的保温时长。 |
| 总超时 min | 每段变温、等待到温、到温确认和保温的总时间上限；必须大于理论最低所需时间。暂停不计入。 |

速率/时间模式的第一段从**启动瞬间实测温度**开始，后续段从上一段目标开始。软件线性斜坡约每 2 秒更新一次设定值。阶跃模式在该段开始时直接写入目标，启动时也不会先把目标提高到当前实测温度。所有设置均回读确认。指定变化时间约束的是**设定值**，实际温度能否跟随取决于加热和制冷能力。

例如 `245 K → 250 K`：选“速率”、梯度值 `1`，表示 1 K/min，设定值约 5 分钟到达 250 K；或者选“时间”、梯度值 `10`，表示设定值用 10 分钟完成这 5 K 的变化。

“等步长生成”可输入起点、终点、正步长、变温速率、每点保温时间，一次生成完整表格。支持升温或降温，包含首尾；最后一步可小于步长。生成后仍可逐行编辑。

定时阶跃不使用到温容差和稳定秒数决定切换，传感器状态检查、数字有效性检查与仪器温度保护仍有效。其余方式：实际温度进入“目标 ± 到温容差”后，需连续满足“到温确认秒数”才开始保温。保温期间超差会重新进行到温确认，并把该段保温计时清零。保持时间为 0 时会在到温确认后转入下一段。

## 暂停、停止与结束

- **↻ 重新开始 / Refresh**：从当前程序表第 1 个温度点重新执行，清零段号与计时并立即运行。暂停或运行中均可使用；保留当前 PID 控温档位，不清空曲线、不覆盖 CSV。与“继续”不同，“继续”保留暂停前的计时和位置。

- **暂停**：冻结软件设定值和程序计时，加热器继续控制在暂停时的设定值；再次点击“继续”恢复。
- **关闭加热**：终止程序并将选定输出的加热档位设为 Off，通过回读确认。
- **全部输出关闭 · All Off**：关闭 336 的全部四个输出并回读确认。
- **完成后关闭输出**：仅在明确选择此项时，末段完成后关闭选定输出。
- **完成后保持末温**：默认行为；末段完成后继续恒温和监测。暂停会保持当前目标；只有明确点击“关闭加热”或“All Off”才主动关闭输出。故障保护仍可能关闭输出。
- 正常退出运行中的程序时，界面要求先关闭当前输出；监测模式下断开连接保留仪器原设置。

控温开始时，程序先关闭所选输出，再设置闭环 PID、所选输入、起始设定值，禁用仪器内置 ramp，关闭所选输出的 power-up enable，回读确认后才启用所选加热档位。它不改变 PID 数值、传感器类型、校准曲线、加热器电阻和电流上限，也不恢复启动前的加热档位。

## 故障与运行条件

运行中遇到输入异常、温度数值无效、阶段超时、外部更改设定值/模式/单位/档位，程序会中止，并尝试关闭当前输出。通信失败时不会显示虚假的“已关闭”：界面明确提示**关闭未确认，需现场按仪器 All Off**。

软件不再要求自定义最低、最高温度；仍检查温度数字有效性、传感器状态、仪器已有的输入温度上限，不改写硬件保护设置。拔 USB、程序被强制结束、电脑断电时，软件无法保证关闭加热；仪器可能继续保持最后设定值。请根据装置设置仪器输入温度上限及独立保护。程序运行时会请求 Windows 保持唤醒，但不能阻止手动休眠、系统强制重启或断电。采样间隔异常超过 15 秒后不会自动追赶斜坡，而会中止并尝试关闭输出。**断线后不会自动恢复运行。**

软件只控制加热输出，降温需要你们装置已有的制冷系统。工作区间 0–1505 K 是软件输入边界，绝不代表你的传感器、样品或装置允许该温区。此版本支持 336 标准 A–D 四输入、加热输出 1–2；未实现选件扫描通道、外部制冷控制或多回路同时编程。

## 数据、程序与演示

- 主界面“全部温度点”默认显示全部 23 个目标和保持时长，按编号从上到下、再从左到右执行。“编辑程序表（可滚动）”用于修改全部行。
- **temperature_data/** 保存用户温度数据，按日期、真实/演示、输入通道分文件，例如 `20260912_REAL_A_10s.csv`。仅有 `temperature_K,local_time` 两列；温度单位 K，当地时间附 UTC 偏移（例如 `2026-09-12 13:08:40.000 -05:00`）。
- 每个 10 秒时间区间保存一次真实测量，写入实际采样时间（受采样周期和通信延迟影响，并非伪造整十秒时间）。文件自动追加并逐条刷新，重连不会覆盖已有数据；断线期间不会补造测量值。输入异常时温度留空，对应状态保存在原始日志。
- 历史记录按相同规则整理到这些文件，全部原始 CSV 仍在 logs/；独立升温实验原始文件仍在原实验文件夹。点击“打开数据记录文件夹”可查看这些 10 秒文件。

- 每次连接自动在 **logs/** 新建 CSV 和操作日志，区分 `_REAL` 与 `_SIM`。CSV 包含时间、A–D 温度和状态、设定值、加热百分比、段号和保温计时。异常输入可在原始数据中为 0，必须结合对应 `*_status`（0 为有效）使用。
- 曲线显示选定输入实测温度与仪器设定值，最多保留最近 1800 点；CSV 保留全部采样。CSV 使用 K，Excel 可打开。
- “保存 / 导入”使用 JSON 温度程序。导入不会自动执行，也不导入硬件温区或加热档位。
- 含“阶跃”的程序使用 JSON 版本 2，需要当前新版可执行程序；仍兼容原有速率/时间模式的版本 1 文件。
- 演示模式不访问任何硬件，可用来练习开始、暂停、停止和温度表格操作。演示温度范围 80–300 K 只用于模拟。
- `recipes/示例_升温阶梯.json` 和 `recipes/示例_定时变温.json` 是编辑示例；实机运行前须按装置修改。

## 源代码与验证

源代码位于 **src/**；在源代码项目根目录运行 **scripts/build.ps1** 可重新生成可执行程序。串口固定为 57600 baud、7 数据位、Odd 奇校验、1 停止位、无流控。使用 LF 发送、按行读取 CRLF 回复，并在消息间隔至少 70 ms。

```powershell
.\scripts\build.ps1
.\LakeShoreControl.exe --self-test "$PWD\test-results.txt"
.\LakeShoreControl.exe --demo
.\LakeShoreControl.exe --connect COM6
.\LakeShoreControl.exe --connect COM6 --recipe "recipes\默认温度程序.json"
```

`--connect` 只会自动连接并监测；`--self-test` 不访问实际仪器。`--probe COM6 result.json` 只查询设备信息与当前配置，将结果保存到文件。
